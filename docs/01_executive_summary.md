# Executive Summary: *Leela: Chronicles of Bharat*

## 1. Project Overview
*Leela: Chronicles of Bharat* is an interactive, non-commercial, and lightweight 3D endless-runner game designed specifically for educational exhibitions, cultural festivals, and community events. To maximize accessibility and eliminate user friction during live events, the game is built using **Three.js (WebGL/WebAssembly)**. Players can instantly start playing by scanning a QR code on their mobile devices—with zero downloads, zero installations, and zero ads.

Inspired by the teachings, stories, and sacred geography associated with Lord Krishna, the game provides a completely free, ad-free, and non-monetized educational experience.

## 2. The Event Vision
Our goal is to create a captivating, interactive cultural installation:
* **Zero Friction:** Immediate play via mobile browsers (Safari/Chrome) upon scanning a QR code at the event venue.
* **Pure Education:** Unlocking historical narratives, environmental storytelling, and interactive puzzle gates without commercial interruptions.
* **Event Integrations:** Local multiplayer leaderboards projected onto large display screens at the venue to drive community engagement and friendly competition.

## 3. Key Product Pillars
1. **Lightweight WebGL Runner:** A fast-loading, responsive 3D endless runner optimized for mobile web browsers using Three.js.
2. **Interactive Puzzles:** Non-intrusive heritage challenges (Sudarshan Gates, Flute Melodies) that reward players with story progression and high scores.
3. **Pure Educational Loop:** Players gather knowledge scrolls (*Gyan Patras*) to rebuild 3D monument dioramas, unlocking illustrated narratives.
4. **Local Event Leaderboards:** Real-time scoring systems to show high scores on the event's main display screen.

## 4. Platform & Tech Stack Selection
* **Primary Platform:** Mobile Web Browser (WebGL / HTML5 via **Three.js**).
* **Secondary Platform:** Standalone PC Kiosk (for physical installation at the event).
* **Backend:** Scalable WebSocket matchmaking (via Nakama or lightweight Node.js/Socket.io server) for real-time leaderboard aggregation on the venue screen.
* **Monetization:** None. The game is entirely free, non-profit, and ad-free.
